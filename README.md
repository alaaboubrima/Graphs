# Graph Representation and Operations

## Overview

This project focuses on the representation of graphs using two primary methods: **adjacency matrices** and **adjacency lists**. The aim is to evaluate and compare these methods in terms of their theoretical and practical performance. The project involves implementing various graph operations and analyzing their complexities.

## Project Important points


1. **Objectives**
   - To find the most efficient representation of a graph between adjacency matrices and adjacency lists.
   - Research both methods, implement operations for each (Using C programming language), and compare their theoretical and experimental complexities.


2. **Graph Representations**

   **Adjacency Matrix**:
   - Represents a graph using a 2D array where matrix[i][j] indicates the presence of an edge between vertices i and j.
   
   **Adjacency List**:
   - Represents a graph using a list where each vertex has a list of adjacent vertices.
